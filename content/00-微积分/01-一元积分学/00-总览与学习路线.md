# 总览与学习路线

> [!abstract] 学习主线
> 一元积分学围绕一个问题展开：如何从局部变化率、密度或微小量恢复整体累积量。目录按“概念与基本定理 → 计算方法 → 定积分求值与近似 → 应用 → 反常积分 → 总结”组织。

## 新版讲义读法

> [!question] 先定位问题
> 一元积分学不是先问“怎样套积分公式”，而是先问：当我们只知道局部贡献率、离散测量值、曲线高度或变化率时，怎样可靠地恢复整体量？

本目录后续每一节都按同一条教学脉络阅读：

| 讲义环节 | 在一元积分学中的具体含义 | 常见落点 |
| --- | --- | --- |
| 困境 | 曲边面积、变速位移、非均匀密度、复杂区域或无穷区间不能直接用有限公式处理。 | 定积分概念、应用建模、反常积分 |
| 原有方法的边界 | 常速公式、有限矩形、图像直觉和代数公式都有用，但不能单独给出稳定定义。 | Riemann 和、可积性、数值积分 |
| 思想动作 | 切分、取样、求和、夹逼、控制误差、换尺度、反向恢复原量。 | 全章主线 |
| 现代定义 | 把“无限细分后稳定的累积量”写成定积分，把“反向求导”写成原函数。 | 定积分定义、原函数、反常积分 |
| 定理条件 | 说明连续、可积、区间方向、正负、收敛等条件在保护什么。 | 基本定理、比较判别 |
| 分层证明 | 先给图像和单位解释，再给关键不等式或极限骨架，必要时展开严格证明。 | 可积性、基本定理、误差估计 |
| 例题练习 | 定义型、图像型、计算型、应用型、证明型、反例型分开训练。 | 每页课后题 |
| 反例边界 | 看见哪里不能反推、不能任意拆分、不能跨奇点、不能把净量当总量。 | 性质、应用、反常积分 |
| 思想收束 | 每节最后回答“本节学到的动作是什么”。 | 总结复习与知识谱系 |

> [!quote]- 讲义取舍
> 抄写目录中的 MIT/Paul 路线提供计算和例题密度，Apostol/Abbott/Tao 路线提供上下和、可积性与证明骨架，历史材料提供“为什么要发明积分”的困境线索。本目录不会把所有材料堆进正文，而是把它们压缩成可学习的思想动作。

## 为什么不能只把积分学整理成公式目录

若把一元积分学只整理成“公式目录”，学习路线容易失焦：应用题会退化为套公式，计算题会退化为找技巧，反常积分会退化为背判别，历史材料也会变成人名附录。新版讲义模板要求每页都先说明困境，再把原有方法的边界、现代定义、符号说明、定理条件、分层证明、例题练习和反例边界串起来。

> [!note] 现代定义与符号说明
> 本目录的符号核心有三组：$\int_a^b f(x)\,dx$ 表示固定区间上的净累积数；$\int f(x)\,dx$ 表示原函数族；$F(x)=\int_a^x f(t)\,dt$ 表示由累积生成的新函数。总览页不替代各节定义，只提醒读者先分清这三种读法。
