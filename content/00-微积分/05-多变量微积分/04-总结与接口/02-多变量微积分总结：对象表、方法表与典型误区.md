## 一张总图

多变量微积分可以从两条主线理解：

1. 局部线：从函数值怎样变化，走向梯度、切平面、极值。
2. 累积线：从小面积或小体积怎样相加，走向二重积分、三重积分和应用。

## 方法表：从目标倒推工具

| 题目目标 | 优先方法 | 关键检查 |
| --- | --- | --- |
| 判断多变量极限是否不存在 | 找两条路径给出不同结果 | 路径反例只能否定极限，不能证明极限存在。 |
| 证明多变量极限存在 | 用统一估计、夹逼或极坐标估计 | 估计必须覆盖所有逼近路径。 |
| 求局部线性近似 | 写全微分或切平面 | 先确认函数在点附近可微。 |
| 估计测量误差对结果的影响 | 用全微分 \(df\) 估计 \(\Delta f\) | 保留单位，并用绝对值给最大误差上界。 |
| 求某方向变化率 | \(D_{\mathbf u}f=\nabla f\cdot\mathbf u\) | 方向向量必须单位化。 |
| 求隐式关系中的导数 | 对 \(F=0\) 使用链式法则，写 \(dF=0\) | 解 \(dy/dx\) 时检查 \(F_y\ne0\)，解 \(z_x,z_y\) 时检查 \(F_z\ne0\)。 |
| 找增长最快方向 | 使用梯度方向 | 梯度在输入空间里，不是在曲面上画出的上坡线。 |
| 分析空间曲线局部几何 | 由 \(\mathbf r'(t)\)、弧长和 \(\vec T\) 进入曲率与局部标架 | 速率为 \(0\) 或 \(\vec T'\) 为 \(0\) 的点要单独处理。 |
| 判断无约束极值 | 解 \(\nabla f=\mathbf 0\)，再用 Hessian | 还要考虑不可微点和定义域边界。 |
| 判断闭区域上的最大最小 | 内部临界点加边界比较 | 闭且有界时才有保证取得最值的背景。 |
| 解光滑等式约束极值 | 写 \(\nabla f=\lambda\nabla g\) 与约束方程 | 不要漏掉约束不光滑或 \(\nabla g=\mathbf 0\) 的点。 |
| 建立二重积分 | 画区域，决定先固定哪个变量 | 上下限要描述同一个区域。 |
| 改变积分次序 | 把区域重新切片 | 不只是交换 \(dx,dy\)，上下限通常也要改。 |
| 建立极坐标二重积分 | 把圆、射线、距离平方改写成 \(r,\theta\) | 角度范围和半径范围都要来自同一个区域。 |
| 处理无界区域或瑕点积分 | 先截断区域或挖掉小邻域，再取极限 | 不要直接把它当普通有界区域上的二重积分。 |
| 换坐标积分 | 写变换、区域、Jacobian | 极坐标有 \(r\)，柱坐标有 \(r\)，球坐标有半径平方和角度因子。 |
| 检查换变量是否重复覆盖 | 看 \(J\ne0\) 与变换是否一一对应 | \(J\ne0\) 只保证局部不压扁，不保证整块区域没有重扫。 |
| 求区域上的函数平均值 | \(\bar f={1\over A(D)}\iint_D f\,dA\) 或 \({1\over \operatorname{Vol}(E)}\iiint_E f\,dV\) | 分母是区域大小；质量加权平均要除以总质量。 |
| 求质量、质心、惯量 | 先写 \(dm\)，再按目标加权 | 分母是质量、面积还是体积，要由平均方式决定。 |
| 求平面薄板的矩和质心 | \(M_x=\iint y\,dm,\ M_y=\iint x\,dm\) | 下标表示关于哪条轴取矩，不表示乘哪个坐标。 |
| 求联合密度下的概率或期望 | \(P(G)=\iint_G p\,dA\)，\(E[X]=\iint_S x\,p\,dA\) | 先检查 \(p\ge0\) 且总积分为 \(1\)。 |
| 求图像曲面面积 | 写 \(dS=\sqrt{1+g_x^2+g_y^2}\,dA\) 再在投影区域积分 | 不要把投影面积 \(dA\) 当真实曲面面积。 |

## 误区表：每次做题前后都值得扫一遍

| 常见误区 | 为什么错 | 正确检查 |
| --- | --- | --- |
| 只沿 \(x\) 轴和 \(y\) 轴看极限 | 多变量可以沿无穷多条路径逼近 | 找反例路径或做统一估计。 |
| 有偏导就认为可微 | 偏导只看坐标方向 | 可微要求整体线性近似成立。 |
| 把 \(df\) 当作精确变化 | 全微分通常只是一阶近似 | 估计误差用 \(df\)，精确变化要算 \(\Delta f\)。 |
| 隐式求导忘记变量依赖 | \(y\) 或 \(z\) 可能随底层变量变化 | 先写 \(F(x,y(x))=0\) 或 \(F(x,y,z(x,y))=0\)。 |
| 把 \(\nabla f\) 画成曲面上的箭头 | 梯度生活在输入空间 | 它垂直等值线或等值面，指向函数值增长最快方向。 |
| 方向导数忘记单位化方向 | 点积公式要求方向向量长度为 \(1\) | 先把方向向量除以长度。 |
| 曲率或法向量在退化点硬套公式 | 速率为 \(0\) 或 \(\vec T'=\vec 0\) 时方向信息退化 | 先检查定义条件，再换参数或单独分析。 |
| 临界点等于极值点 | \(\nabla f=\mathbf 0\) 只是候选条件 | 用 Hessian、路径比较或直接比较函数值。 |
| Hessian 判别式为 \(0\) 时硬下结论 | 二阶判别失效 | 需要更高阶信息或其他比较方法。 |
| 约束题直接解 \(\nabla f=\mathbf 0\) | 可行方向被约束限制 | 用消元、参数化或 Lagrange 乘子。 |
| Lagrange 乘子法不查边界 | 不等式约束或区域边界可能有最值 | 分内部、边界、角点、奇点处理。 |
| 改积分次序只换微分符号 | 区域切片方式改变了 | 重新画区域并写新上下限。 |
| 极坐标角度范围总写 \(0\) 到 \(2\pi\) | 只有完整绕一圈的区域才这样写 | 先画射线边界，再决定 \(\theta\) 的起止。 |
| 无界区域上直接套普通二重积分 | 区域没有有限边界，或函数在某处爆掉 | 先写截断极限，必要时分区处理。 |
| 极坐标、柱坐标漏 \(r\) | 小片面积或体积变了 | 换坐标必须乘 Jacobian。 |
| 看到 \(J\ne0\) 就不查一一性 | 局部小片没压扁，不等于整块区域没重复覆盖 | 对角度范围、周期变量和折叠变换额外检查。 |
| 曲面面积直接用 \(dA\) | \(dA\) 只量投影，不量倾斜曲面 | 图像曲面要乘 \(\sqrt{1+g_x^2+g_y^2}\)。 |
| 球坐标角度约定混乱 | 不同记号对极角和方位角命名不同 | 先写清楚 \(x,y,z\) 与新变量的关系。 |
| 求平均值分母用错 | 不同平均有不同权重 | 体积平均除体积，质量平均除质量。 |
| 平面薄板矩的下标看反 | \(M_x\) 是关于 \(x\) 轴的矩，要乘到 \(x\) 轴的距离 \(y\) | 质心公式是 \(\bar x=M_y/m,\ \bar y=M_x/m\)。 |
| 把概率密度值当成概率 | 密度要乘小面积并积分才给出区域概率 | 用 \(\iint_G p\,dA\) 计算事件概率。 |

## 极值题的决策流程

极值题最容易漏候选点，可以按下面顺序检查。

| 步骤 | 要问的问题 | 常用工具 |
| --- | --- | --- |
| 1 | 可行集合是什么？ | 定义域、约束方程、边界条件 |
| 2 | 是无约束还是有约束？ | 无约束临界点或 Lagrange 方程 |
| 3 | 可行集合有没有边界或角点？ | 参数化边界、分段检查 |
| 4 | 有没有不可微点或约束奇点？ | 单独代入或局部比较 |
| 5 | 题目要局部还是全局？ | Hessian、边界比较、函数值比较 |

> [!warning] 约束极值的核心不是乘子
> Lagrange 乘子只是把“沿所有可行切向方向的一阶变化为零”写成方程。真正不能忘的是可行集合本身。

## 多重积分题的决策流程

多重积分题先画区域，再写小片。

| 步骤 | 要问的问题 | 常用工具 |
| --- | --- | --- |
| 1 | 积分对象是平面区域、空间区域、薄板还是实体？ | \(dA\)、\(dV\)、\(dm\) |
| 2 | 区域是否无界，函数是否有瑕点？ | 截断极限、挖掉小邻域 |
| 3 | 区域用哪种坐标最自然？ | 直角、极坐标、柱坐标、球坐标 |
| 4 | 先固定哪个变量最省事？ | 竖切、横切、先投影 |
| 5 | 换坐标后小片怎样缩放？ | Jacobian |
| 6 | 被积函数代表什么贡献？ | 高度、密度、概率、位置加权、距离平方加权 |

> [!tip] 小片语法
> 多重积分应用统一写成
> $$
> \text{总量}=\int \text{小片贡献}.
> $$
> 难点通常不是积分号，而是“这个小片贡献到底是什么”。

## 复习顺序建议

如果是考前或阶段复习，可以按下面顺序做。

| 轮次 | 目标 | 做法 |
| --- | --- | --- |
| 第一轮 | 认对象 | 只看题目，判断属于极限、导数、极值还是积分。 |
| 第二轮 | 选方法 | 不计算，先写出应使用的定理、方程或坐标。 |
| 第三轮 | 做计算 | 对每类题选少量典型题完整算到最后。 |
| 第四轮 | 查误区 | 用本节误区表逐项检查：边界、单位方向、Jacobian、分母。 |

> [!success] 完成标准
> 看到一道多变量题时，若你能先说清楚“对象是什么，允许怎样移动，正在累积什么”，再选择对应工具，那么本章的骨架就已经建立起来了。
